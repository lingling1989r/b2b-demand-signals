# URL 发现与竞品池

适用于平台工具能读 URL、不能按关键词搜索，或原生搜索覆盖不足时。先发现候选，再经 ClaudeBaby 核验，最后评级；候选数量与已核验线索数量分别统计。

## 搜索引擎发现

使用宿主现有搜索能力，按目标市场组合“品类＋采购/求助表达＋平台域名”。例如 `site:facebook.com "jeans" "looking for supplier"`；德语可尝试 `site:facebook.com "Jeans" "Lieferant gesucht"`，法语可尝试 `site:facebook.com "jeans" "recherche fournisseur"`。这些是查询模板，不是已找到的线索；根据结果调整本地表达，语言不能证明账号所属国家。

保留查询词、语言、搜索引擎、发现时间、结果 URL 与摘要。摘要只作筛选提示，不能充当采购原话、发布时间或已核验证据。提取原帖/主页链接，去除追踪参数、按平台 ID 或规范 URL 去重；保持帖子定位必需的参数。

将原帖 URL 交给 ClaudeBaby 单帖工具；主页 URL 先核主页身份，再读取帖子并按帖子自己的发布时间过滤。按实时 schema 调用，不把个人资料、群组或搜索页 URL 当作已支持的主页输入。工具不支持或返回失败时留在待核区，记录原因，不静默丢弃。

搜索时间筛选只用于缩小候选集，搜索结果日期不能代替原帖日期。[Google 的 site 查询说明](https://developers.google.com/search/docs/monitor-debug/search-operators/all-search-site)明确不保证返回全部已收录 URL；未收录、新发布及不可访问内容可能遗漏。报告必须说明覆盖有限，不能把未搜到写成“近 7 天没有需求”。

## 用户提供或搜索建立主页池

优先复用已有竞品/相关主页池；没有时，询问用户可提供的竞品名称、官网或公开主页，同时可按已知品类和市场搜索建立候选池，无须等待名单才能开始发现。根据官网公开社媒链接与 ClaudeBaby 主页资料核对归属；同名或身份不明的主页标待核，不自动纳入已确认池。

每个池条目保留 pool_id、主页 URL/平台 ID、名称、角色（竞品/行业主页/潜在买家）、来源（用户/搜索）、发现查询、归属证据、目标市场证据、纳入理由、核验状态、最近采集时间与游标（工具支持时）。竞品本身不是采购客户，竞品广告、卖货帖不算其作者的采购需求。

按任务时间窗口与调用预算读取池内主页帖子，保存原始返回，按帖 ID 去重，在本地用关键词、采购表达及可用的语义检索筛候选。语义命中只帮助召回，评级前仍须读取原文，核对谁在买、买什么、何时发布及需求是否关闭。仅有商品词或相似主题不构成采购意图。

已有历史采集时可增量更新；工具不支持游标时只用实际支持的参数，并说明截断情况。用户要求持续监测时记录建议频率、窗口和预算；单次研究不自动创建定时任务，也不声称已启动持续监测。本地索引只覆盖已采集内容，不能发现池外新账号。

群组与评论只有实时目录中存在且实际可用的对应工具时才能采集；主页帖子接口不能替代它们。评论需求的主体是评论者，不能归到竞品/父帖作者名下。未能读取评论时明确写“评论未覆盖”。

## 核验、交付与停止条件

只有 ClaudeBaby 返回的原文、作者与时间等证据支持时，才进入既有 ABC 评级流程；日期未知、账号归属未明或读取失败的候选单独待核。站外摘要即使出现明确采购措辞，也不能直接升为已核验 A/B。

在现有“查询与覆盖”页记录发现、读取、筛选、核验各阶段数量，池大小、实际采集主页/帖子数、截断/失败及未覆盖渠道；在“历史/待核”区保留未核验候选。没有有效取数时 A/B 数量未知；完成有限范围核验后可报告“本次已核验样本中 0 条符合”，不能外推全平台无需求。

达到本次预算/调用/翻页边界或出现鉴权、余额、权限错误时停止相应取数，保留已取得的证据与候选。搜索不可用且没有种子 URL 时，请用户提供主页/原帖链接；不要循环改写关键词假装扩大了覆盖。
