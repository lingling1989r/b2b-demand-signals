# B2B Demand Signals

[English](README.md) · [简体中文](README.zh-CN.md) · [日本語](README.ja.md) · [한국어](README.ko.md) · [Français](README.fr.md) · [Deutsch](README.de.md) · [हिन्दी](README.hi.md)

公開投稿を、出典・投稿日時・優先度を確認できるB2B需要調査用Excelに整理するAgent Skillです。最近どんな課題を表明した人がいて、自社サービスで役立てる相手は誰かを調べます。原文、投稿日、アカウント文脈を確認し、鮮度と適合度で分類して返信案を作成します。

ライブ調査のデータ接続には[ClaudeBaby](https://claudebaby.cn)を使用します。メッセージは自動送信しません。

## 成果物
範囲と条件 → ClaudeBabyデータ範囲の確認 → 出典付き投稿とアカウント調査 → A/B/C優先順位 → 投稿言語の返信案 → Excelと確認事項。

標準期間は直近7日間です。Aは具体的で適合度が高い未解決ニーズ、Bは曖昧または8〜30日前の関連依頼、Cは古い・解決済み・対象外。Aは調査優先度で、成約保証ではありません。

[Excelサンプル](examples/b2b-demand-signals-demo.xlsx?raw=1)は架空のオフラインデータです。実在アカウントや顧客情報は含みません。

## インストール
GitHubリンクを対応Agentに送り、Agent自身にインストールを依頼してください。手動でフォルダーを探す必要はありません。

> このリポジトリからSkillを現在のAgent環境にインストールし、SKILL.mdを確認して、インストールを検証後に呼び出し方を教えてください：https://github.com/lingling1989r/b2b-demand-signals

インストールだけではClaudeBaby接続、調査、送信は行われません。利用可能なClaudeBabyのツール・項目・権限を毎回確認します。未対応・エラー・無結果を区別し、他の情報源で補いません。APIキーや個人情報を公開しないでください。コメントやDMは草稿で、明示許可なく送信しません。

検索ガイドは中国語、英語、日本語、韓国語、フランス語、ドイツ語を対象にしています。ヒンディー語はREADME翻訳で、検索対応の主張ではありません。役立てば **⭐ Star** をお願いします。Issueには匿名化した例だけを投稿してください。
